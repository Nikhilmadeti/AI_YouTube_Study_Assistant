# AI YouTube Study Assistant

AI YouTube Study Assistant is a simple web application built with **Python**, **Gradio**, and **Google Gemini**. It allows users to generate study notes from YouTube videos and ask questions about the video content.

## Features

- Generate video summary
- View video information
- Chat with the video transcript
- Powered by Google Gemini AI
- Simple Gradio interface

## Technologies Used

- Python
- Gradio
- Google Gemini API
- YouTube Transcript API
- yt-dlp

## Installation

1. Clone the repository.
2. Install the required packages:

```bash
pip install -r requirements.txt
```

3. Create a `.env` file and add your Gemini API key:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

4. Run the application:

```bash
python app.py
```

## Usage

1. Paste a YouTube video URL.
2. Click **Generate Summary**.
3. Read the generated study notes.
4. Open the **Chat** tab and ask questions about the video.
